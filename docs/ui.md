Redesign this CODM account shop as a modern shadcn/ui marketplace.

Style direction:

- Inspired by shadcn/ui dashboard blocks, StockX, and Back Market.
- Neutral background, subtle borders, small radius, dense but elegant product cards.
- Use Tailwind CSS and shadcn/ui components only.
- Avoid flashy gaming gradients, glassmorphism, neon effects, and marketing hero layouts.
- Make the product browsing experience the first screen.

Pages:

- Home: marketplace layout with top navigation, search, featured carousel, filter chips, and account cards.
- Listing: left/sidebar or sticky filter area, sort menu, compact account cards.
- Detail: image gallery, price/action panel, verified account attributes, risk/guarantee section.

Components:

- Button, Card, Badge, Input, Tabs, Select, Sheet, Separator, Skeleton.
- Use lucide icons.
- Product cards should show price, region, rank, skins count, rarity tags, and availability.
